## **중고 전자기기** 거래 플랫폼 : SAPHY
> <b>판매자와 구매자 모두가 신뢰할 수 있는</b> 전자기기 중고 거래 플랫폼
<br>

![홍보 이미지 1](https://github.com/user-attachments/assets/5ec04c62-d418-4158-b3cf-ff0396b39edf)

<br>
전자기기의 경우 비교적 고가의 상품이 많으며, 기기의 기술적인 결함이 눈에 보이지 않는 경우가 많아 사기의 위험이 큽니다.
<br>
그래서 중고 제품 또한 높은 가치를 가지고 있음에도 불구하고 원활하게 중고 거래가 이루어지지 않고 있습니다.
<br>
따라서 Saphy는 전자 기기의 중고 거래가 쉽게 이루어질 수 있도록, <b>판매자와 구매자 모두가 신뢰할 수 있는 플랫폼</b>이 되고자 합니다.


## 🌟 주요 기능
 
    
<table>
  <tr>
    <th rowspan=4 width='100px'>제품 판매</th> 
  </tr>
  <tr>
      <td>판매하고 싶은 전자기기를 몇 단계의 간단한 절차를 통해 손쉽게 등록할 수 있습니다.<br> 
        상세한 설명과 사진만 첨부하면, 제품을 찾는 사람들이 바로 확인할 수 있습니다.</td>
  </tr>
  <tr>
    <td>거래 과정에서 사기나 불공정한 상황을 방지하기 위해 안전 결제 시스템을 제공합니다.<br> 
      또한, 판매자가 거래 완료 후에도 후기 시스템을 통해 평판을 관리할 수 있습니다.</td>
  </tr>
  <tr>
    <td>플랫폼 내에서 구매자와 직접 소통하여 빠른 거래가 가능하며, 판매 알림 기능을 통해 더욱 효과적으로 거래를 진행할 수 있습니다.</td>
  </tr>
  <tr>
    <th rowspan=4>제품 구매</th> 
  </tr>
  <tr>
    <td>최신 전자기기부터 빈티지 가전제품까지 다양한 카테고리에서 자신에게 맞는 제품을 찾아볼 수 있습니다.<br>
      상세 검색 기능을 통해 원하는 조건의 제품을 빠르게 찾을 수 있습니다.</td>
  </tr>
  <tr>
    <td>각 판매자는 후기를 통해 신뢰도를 평가받기 때문에, 검증된 판매자로부터 안심하고 제품을 구매할 수 있습니다.<br>
      제품 상태, 가격, 판매자 정보를 확인하고 안전하게 거래를 진행하세요.</td>
  </tr>
  <tr>
    <td>중고 거래 플랫폼의 가장 큰 장점은 합리적인 가격입니다.<br>
      원하던 전자기기를 시중가보다 저렴한 가격에 구매할 수 있으며, 거래를 통해 더 큰 가치를 얻을 수 있습니다.</td>
  </tr>
  
 
  
</table>


## 💻 기술 스택

### Frontend 🏪
<table>
  <tr>
    <th>Flutter</th>
    <td>애플리케이션 개발 및 배포 시 여러 플랫폼에서 이를 가능할 수 있도록 도와주는 크로스 플랫폼 프레임워크를 사용했습니다.</td>

### Backend 🚚
<table>
  <tr>
    <th>기술</th>
    <th>설명</th>

### Devops ⚙️ 
<table>
  <tr>
    <th>기술</th>
    <th>설명</th>
  </tr>
  <tr>
    <td>AWS</td>
    <td>Amazon Web Services는 클라우드 컴퓨팅 서비스로, 서버, 스토리지, 데이터베이스 등 
        다양한 인프라를 온디맨드로 제공하며 애플리케이션 배포와 관리를 손쉽게 지원합니다.</td>
  </tr>
  <tr>
    <td>Jenkins</td>
    <td>지속적 통합 및 배포(CI/CD)를 자동화하는 오픈소스 도구입니다. 
        빌드, 테스트, 배포를 간편하게 관리할 수 있습니다.</td>
  </tr>
  <tr>
    <td>Docker</td>
    <td>애플리케이션과 그 의존성을 컨테이너로 패키징하여 어디서든 일관된 환경에서 
        실행할 수 있도록 해주는 가상화 플랫폼입니다.</td>
  </tr>
  <tr>
    <td>Redis</td>
    <td>인메모리 데이터베이스로, 세션 저장소, 캐시, 실시간 데이터 처리에 활용되며 
        빠른 데이터 접근이 가능합니다.</td>
  </tr>
</table>
